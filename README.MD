# Практична робота №3
Тема: Застосування метакласів, декораторів та паттернів проектування для розширення можливостей класів у Python.
Виконав студент групи БІКСб12540, Смоляков В.І.

## Опис файлів
* `t1.1.py` - система плагінів із метакласом `PluginMeta` та динамічним створенням класу через `type()`.
* `t1.2.py` - система конфігурації на базі `__init_subclass__()` та типізованого дескриптора `ValidatedField`.
* `t2.1.py` - параметризовані декоратори функцій: `@cache`, `@rate_limit`, `@log`.
* `t2.2.py` - декоратори класів: `@auto_repr`, `@frozen`, `@log_methods` та їх комбінування.
* `t3.1.py` - система логування з паттернами Singleton (через метаклас) та Factory Method.
* `t3.2.py` - To-Do List із використанням Observer, Strategy та архітектурного шаблону MVC.
